# dsh-model-deck

> DSH（DeepSeek Harness）模型选择插件：**模型分组 · 界面美化 · 进度条美化**

A model picker deck for DeepSeek Harness (DSH).

🚧 早期开发中：仓库刚初始化，代码与接口尚未定型。

## 特性（规划）

- **模型分组**：按供应商 / 层级 / 标签分组展示，快速切换模型
- **界面美化**：统一主题、间距与动效，选择弹窗更顺眼
- **进度条美化**：上下文占用与请求进度可视化，状态一眼可见
